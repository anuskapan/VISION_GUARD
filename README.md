# 👁️VISION_GUARD-HUMAN EYE DISEASE PREDICTION SYSTEM

A deep learning–based web application developed to predict and classify human eye diseases using medical image analysis and machine learning techniques.

This project leverages artificial intelligence and computer vision to assist in the early detection of eye-related diseases through image-based prediction models.

The system aims to provide a simple, interactive, and efficient platform for analyzing retinal or eye images and generating predictive insights.

---

## 🚀 Features

- 👁️ AI-powered human eye disease prediction  
- 🧠 Deep learning model for image classification  
- 📷 Medical image upload and analysis  
- 📊 Prediction results with confidence scores  
- ⚡ Fast and interactive user interface  
- 🔍 Automated disease detection workflow  
- 📁 Support for image-based datasets  
- 💻 User-friendly web application interface  
- 📈 Data-driven healthcare prediction system
- ✅ Achieved approximately **90% prediction accuracy** during model evaluation 

---

## 🎯 Project Objective

The goal of this project is to:

- Predict eye diseases using deep learning models  
- Assist in early-stage disease detection  
- Automate medical image analysis  
- Improve accessibility to AI-driven healthcare tools  
- Demonstrate practical applications of AI in healthcare  

---

## 📊 Dataset

The model is trained using publicly available eye disease image datasets from Kaggle containing categorized medical eye images for disease classification and analysis.

The dataset includes image samples used for training, validation, and prediction of different eye-related conditions.
